关于我

AI 助手通过这份画像理解你的背景、偏好和协作方式。

身份与背景

  • 使用中文进行交流
  • 使用 Windows 多显示器环境，不同屏幕有不同 DPI 缩放设置

沟通风格

直接、简洁，会明确指出问题所在。委派调研任务时使用结构化格式。

UI/UX 偏好

追求优雅、精致的设计。偏好内联展开动画，反感浮窗式 tooltip。要求适配深色模式。

代码偏好

项目使用 Electron + Web Components。CSS 动画偏好 transition 方式。

    动效规范

    展开 / 收起 · Tab 切换 · 通知

    展开动画

  • 展开卡：opacity 0→1 + scale(.98→1) + translateY(-6px→0)
  • 缓动：cubic-bezier(0.23,1,0.32,1) · 250ms
  • 时间线卡片：opacity 1→.5 · 180ms
  • 两者同时启动
    • 展开卡片

    收起动画

  • 展开卡：opacity 1→0 + scale(1→.98) + translateY(0→-6px)
  • 缓动：ease-in · 180ms
  • 时间线卡片：opacity .5→1 · 180ms
  • 动画完成后移除展开卡 DOM
    • 收起卡片

    Tab 切换

  • 内容区：opacity 0→1 · 150ms ease-out
  • 下划线：transition: all .15s
  • 切换时取消所有编辑态

    • 通知提示

  • 进入：opacity 0→1 + translateY(-8px→0) · 200ms
  • 停留 3s 后退出
  • 退出：opacity 1→0 · 150ms
    • 交互规则：① 点击时间线卡片展开/收起浮层卡，同时只展开一张；② 点击展开卡内"编辑"按钮进入编辑态，表单替换卡内容； ③ 保存/取消退出编辑态，保存后刷新数据；④ 切换 Tab 时收起所有展开；⑤ prefers-reduced-motion 时跳过动画； ⑥ 通知提示固定在 Tab 栏下方，3s 自动消失。
