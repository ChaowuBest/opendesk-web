    动效规范

    进入 / 退出 · 缓动曲线与时长

    进入动画

  • 蒙层：opacity 0→1 · 250ms ease-out
  • 卡片：scale(.95)→1 + translateY(10px)→0 + opacity 0→1
  • 缓动：cubic-bezier(0.23,1,0.32,1) · 250ms
  • 蒙层与卡片同时启动、同时结束
    • 弹窗卡片

    退出动画

  • 蒙层：opacity 1→0 · 180ms ease-in
  • 卡片：scale(1)→.95 + translateY(0)→10px + opacity 1→0
  • 缓动：ease-in · 180ms
  • 动画完成后 setTimeout 移除 DOM
    • 弹窗卡片
    交互规则：① 点击蒙层或按 Esc 等同取消，触发退出动画；② 确认按钮点击后先执行操作再关闭弹窗；③ 动画期间 pointer-events:none 防止重复触发；④ prefers-reduced-motion 时跳过动画直接显示/隐藏。
