简介

OpenDesk 桌面版是 Intelli OS（智能世界操作系统）的战略子项目，集成了多个智能应用模块，通过 AI 技术提升日常工作和生活的效率。桌面版采用模块化应用架构，与 CLI 版本相比，提供了完整的图形界面、更多 GUI 专属应用以及更丰富的交互体验。

桌面版 vs CLI 版本

特性 CLI 版本 桌面版
界面 终端 TUI 图形界面 (HTML/CSS/JS)
窗口管理 终端控制 Electron BrowserWindow
应用列表 基础应用集 全部应用

系统集成 无 托盘、全局快捷键、单实例
内置浏览器 无 有（CDP 自动化控制）
文件浏览器 无 有（树状/网格视图）
AI 内核 完全共享 完全共享
工具与技能 完全共享 完全共享

安装与首次配置

安装

🪟 Windows

  1. 下载 .msi 安装包
  2. 双击运行安装程序
  3. 从开始菜单启动 OpenDesk

🍎 macOS

  1. 下载 .dmg 安装包
  2. 打开 DMG，拖入 Applications
  3. 从 Launchpad 启动 OpenDesk

常见问题

Q:关闭窗口后 OpenDesk 还在运行吗？
是的。关闭窗口只是隐藏了界面，OpenDesk 会继续在系统托盘中运行。如需完全退出，请右键托盘图标选择"退出"。
Q:如何切换 AI 模型？
在输入框左侧点击模型标签，从下拉列表中选择已配置的模型。也可以在设置面板中修改默认模型。
Q:浏览器登录状态会保留吗？
会的。OpenDesk 会在退出前自动将 session cookies 转换为持久 cookies（30 天有效期），确保登录态跨重启保留。
Q:如何调整界面大小？
使用 Ctrl + = 放大、Ctrl + - 缩小、Ctrl + 0 重置。也可以在设置面板中调整缩放比例（50%~200%）。
Q:全局快捷键不生效怎么办？
可能是快捷键被其他应用占用。请检查是否有其他应用使用了 Alt + Space（Windows/Linux）或 Option + Space（macOS）快捷键。
Q:如何安装技能？
点击侧边栏的技能中心图标，在技能管理界面中可以从多个技能市场浏览和安装技能。安装后技能会即时生效，无需重启。
Q:如何管理消息渠道？
消息渠道通过插件系统管理。可以在设置中配置飞书、微信等渠道的接入参数，配置完成后 AI 助手会自动处理收到的消息。
Q:配置文件在哪里？
Windows 系统位于 %APPDATA%/opendesk/setting.json，Linux/macOS 系统位于 ~/.opendesk/setting.json。
Q:如何检查更新？
OpenDesk 会自动检查更新（每小时一次）。发现新版本时会弹出更新提示。也可以在设置中手动检查。
