OpenDesk CLI是运行在Shell中的全能办公助手，它基于OpenDesk的基础能力开发，旨在为开发者提供一站式的Agent基础能力。

## 安装

运行下面的命令安装最新版本的OpenDesk CLI：
```shell
npm install -g @bitclub.ai/opendesk-cli
```

或者安装每日构建的最新版本（功能最新，但可能存在不稳定的问题，请谨慎使用~）：
```shell
npm install -g @bitclub.ai/opendesk-cli@nightly
```

> [!TIP]
> 安装前请先移除 0.1.x 之前的旧版本。
