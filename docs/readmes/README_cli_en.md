OpenDesk CLI is an AI assistant running in the terminal, built on the OpenDesk framework, designed to provide developers with a one-stop AI service for office and productivity scenarios.


## Installation

Run the following command to install the latest version of OpenDesk CLI:
```shell
$ npm install -g @bitclub.ai/opendesk-cli
$ opendesk
```

Or install the latest nightly build:
```shell
$ npm install -g @bitclub.ai/opendesk-cli@nightly
$ opendesk
```

> [!TIP]
> The Nightly version provides continuous access to the latest features, but since it has not been fully tested, there may be stability issues. You are welcome to interact with us in the Issues and Discussions section of this repository. We will respond to your questions as soon as possible during working hours ;)

## Key Features

- **Comprehensive Agent Capabilities**: Supports free integration of third-party models, MCP Servers, and A2A Agents (in development). The Agent-oriented file system built with composite indexes allows you to easily manage various local files. Supports command execution in multiple terminals including Bash, Zsh, and Powershell. The built-in planning capability helps you easily complete complex tasks;
- **User-friendly Configuration**: Only the default model for first-time use needs to be configured manually. Subsequent configurations for search engines, email, and to-do items; searching and downloading MCP and Skills... everything is completed through natural conversation, away from cumbersome configuration interfaces and JSON files;
- **Human-Agent Collaboration Design Philosophy**: We don't just want to design an application, but a collection of **applications suitable for both users and agents**; traditional applications are too complex to effectively integrate with agents, while purely dialogue-based approaches have limited efficiency in many scenarios;
