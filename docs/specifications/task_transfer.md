# GUI 任务导入与批量导出

## 入口与范围

设置 → 任务设置 → 任务数据：

- **导入任务**：先打开原生文件选择框，选择一个 ZIP 任务包或现有任务 JSON 后展示预览；选择工作空间和要导入的任务。取消选文件不显示预览弹窗。
- **批量导出**：搜索、多选任务，保存为一个 ZIP 文件，自动包含关联子任务。
- 现有任务页的单任务 JSON / HTML 导出保持兼容。

任务包包含序列化任务记录，包括对话、工具记录、目标及用量等已存在于任务 JSON 中的数据。
外部附件、任务产物和工作目录文件不打包；已有内嵌数据保留。界面明确提示这一范围。

## ZIP 格式 v1

```text
manifest.json
tasks/<task_id>.json
```

```json
{
    "format": "opendesk-task-bundle",
    "version": 1,
    "exportedAt": "2026-09-15T09:00:00.000Z",
    "tasks": [
        {
            "id": "task-a",
            "path": "tasks/task-a.json",
            "parentId": null,
            "name": "Task A"
        }
    ]
}
```

每个任务文件继续使用 `TaskState.toJSON()` 的现有格式。未知包版本拒绝导入。
清单中的名称、父任务信息用于损坏条目的说明及关联组校验；有效条目的实际数据来自任务文件。

限制：1000 个任务，单条目 16 MiB，解压总量 128 MiB，输入/输出文件 64 MiB。
包内仅允许清单及任务路径；拒绝重复路径、重复任务 ID、符号链接、加密条目及不支持的压缩算法。
读取 ZIP 不解压到磁盘；解压器限制实际输出大小并校验长度及 CRC，不能仅依赖 ZIP 声明的大小。

## 导入语义

1. 主进程选择文件并读取快照，renderer 只接收预览信息和随机 token。
2. 预览有效期为 10 分钟；关闭弹窗释放预览。提交消费 token，避免重复提交。
3. 来源 ID 与内容摘要用于识别重复任务；默认不选重复项，主动勾选可导入副本。
4. 每次导入生成新任务 ID，重映射所选任务的父子关系及消息元数据、目标、用量中的任务引用。任务、消息、目标事件和压缩记录的内部时间戳按原先后顺序映射到导入时刻附近（不同时间相差 1 ms），保留数字/ISO 字符串格式，同一时间仍相同；任务更新时间为导入时刻。聊天正文、工具参数/结果及外部文件事实不做字符串替换，耗时、用量保留。来源 ID 仅在溯源信息中保留以识别重复。
5. 未选择父任务的子任务成为独立任务。循环父子关系拒绝导入。损坏的任务及其关联组不可选，其他组可正常导入。
6. 导入任务统一保持停止，活动目标暂停。GUI 预览默认当前工作空间，可通过主页同款工作空间选择器改选；所选目录用于本批任务，不修改应用默认工作空间。主进程提交前校验绝对路径且目录存在。清除来源设备绑定与渠道路由；缺失的模型/Agent 使用本机默认配置，不迁移运行期授权。
7. 按有关联的任务组提交。任务文件使用新 ID 独占创建，成功写入索引后才发布任务列表更新。文件或索引写入失败时撤回该组，其他已成功组保留。
8. 结果显示导入、跳过、失败数量，支持打开导入任务。

`import_metadata` 保存来源 ID、摘要、导入时间和来源工作目录/设备说明，进入任务文件及轻量索引，使重启后仍能识别重复。
TUI `/import task` 复用校验和可靠提交服务；保留旧 JSON 导入的来源工作目录语义，以及现有 prompt 队列入口。

## 导出语义

- 先加载完整任务，在读取时将内存数据序列化为快照；不直接复制可能过期的磁盘文件。
- 运行中的任务不暂停，每个任务记录其读取时的状态；多个任务不是跨任务同时刻的事务快照。
- 先写临时 ZIP，再重命名为最终文件。失败不会留下一个伪装成成功结果的部分任务包。
- 导出说明使用三行 info 框，明确包含内容、排除内容和运行中快照语义。选择按钮为“全选 / 取消”。
- 显示处理进度及最终任务数量，“打开所在文件夹”放在底部“关闭”左侧。

## 实现位置与验证

- `src/main/utils/task-bundle.ts`：文件格式、大小限制、JSON 校验和导入状态归一化。
- `src/main/aikernel/task/transfer.ts`：预览、重复识别、关联组导入和批量导出。
- `TaskManagerState.commitImportedTasks()`：文件及索引提交。
- `src/main/task-transfer-ipc.ts`：文件对话框、预览生命周期、主窗口来源校验及操作互斥。
- `src/renderer/components/taskTransferDialog.js`：选择、搜索、预览、进度、结果和键盘焦点。

自动测试覆盖格式往返、旧 JSON、损坏/超限文件、虚假 ZIP 大小、关联组回滚、活动目标暂停、立即重启恢复、重复导入和 renderer 交互。
相关既有测试包括 TUI 导入、懒加载、持久化、单任务导出及设置页语言切换。
GUI 验证使用独立配置目录；可预设原生文件对话框返回路径，其余 renderer、preload、IPC、任务管理器和存储使用真实实现。
