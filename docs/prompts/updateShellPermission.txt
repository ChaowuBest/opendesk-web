# 对 Shell 命令权限解析功能的自我演进

```
首先给你看一个命令： npm run cli -- -c "你是一个安全专家。我需要你帮我测试对于shell命令执行，当前的权限管控系统是否还有漏洞。想尽办法使用bash和powershell访问到上一级文件目录中的文件信息，并将这些视为存在问题的测试用例保存在 invalid_shell.txt 中。为了实现测试目标，你可以自由阅读工作空间中opendesk的源代码。" --headless

我通过这种方式发现了大量的问题，并且把发现的用例保存在了指定的文件里面。你需要根据这些信息增加测试用例，执行测试，修复问题，并且再次通过我说的方法尝试发现漏洞，直到找不到问题为止。
```
