# 设置 (Settings) GUI 验收测试用例

---

## 前置条件

### P-SET-01：已配置至少一个模型服务商

1. 打开设置页（侧边栏底部工具栏「设置」按钮）。
2. 确保「模型设置」标签页中至少有一个服务商配置。
3. 如无，点击「添加服务商」按钮，填入必要信息并保存。
4. **预期**：模型设置标签页显示至少一个服务商卡片。

### P-SET-02：深色主题已启用

1. 在设置页「通用设置」标签页中，找到外观主题设置。
2. 将主题切换为「深色」。
3. **预期**：设置页整体界面切换为深色主题。

## 测试用例

### TC-SET-001：设置页打开与结构展示

**前置**：无

| 步骤 | 操作                             | 预期结果                                                         |
| ---- | -------------------------------- | ---------------------------------------------------------------- |
| 1    | 点击侧边栏底部工具栏「设置」按钮 | 打开设置页面                                                     |
| 2    | 观察页面整体布局                 | 左侧导航栏 + 右侧内容区布局                                      |
| 3    | 观察左侧导航栏                   | 显示标签页按钮：模型设置、任务设置、搜索设置、通用设置、设置向导 |
| 4    | 观察当前激活标签页               | 默认激活「模型设置」，右侧内容区显示对应设置项                   |
| 5    | 观察页面标题                     | 页面标题或导航中显示「设置」                                     |

**判定**：页面未打开或关键布局缺失 → 失败
