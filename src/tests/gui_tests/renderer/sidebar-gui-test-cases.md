# 侧边栏 (Sidebar) GUI 验收测试用例

--- | 深色主题 | 中 |

## 前置条件

### P-SB-01：已有至少一个任务

1. 在 OpenDesk 主页输入框中输入任意内容并发送，等待 AI 回复完成。
2. 观察侧边栏任务列表，确认出现一条任务。
3. **预期**：侧边栏任务列表显示至少一条任务。

### P-SB-02：已有多个任务（含不同工作空间）

1. 按 P-SB-01 创建至少两个任务。
2. 在不同工作空间目录下各创建一个任务（通过侧边栏「新任务」按钮后切换工作空间）。
3. **预期**：侧边栏任务列表显示 ≥2 条任务，且至少属于两个不同工作空间。

### P-SB-03：侧边栏处于展开状态

1. 打开 OpenDesk 主窗口。
2. 若侧边栏为折叠态，点击折叠态的 Logo 按钮或右侧竖条指示器展开。
3. **预期**：侧边栏显示完整的品牌标题、搜索框、任务列表和底部工具栏。

### P-SB-04：开发者模式已开启

1. 打开 OpenDesk 设置页面（点击侧边栏底部「设置」按钮）。
2. 找到「开发者模式」开关，将其打开。
3. **预期**：侧边栏底部工具栏出现「开发工具」按钮。
