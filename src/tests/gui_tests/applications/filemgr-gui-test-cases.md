## 前置条件

### P-FILE-01：已配置至少一个数据源并完成扫描

1. 打开侧边栏底部工具栏「文件系统」按钮，进入「智能文件系统」页面。
2. 在文件树中勾选一个包含若干文件的本地目录（如 `~/Documents`）。
3. 等待该目录完成扫描。
4. **预期**：数据源卡片区出现对应目录卡片，状态显示「已完成 · N 文件」。

### P-FILE-02：文件树中已勾选当前工作空间目录

1. 按 P-FILE-01 完成配置。
2. 确认「当前工作空间」按钮可见（存在默认工作空间时）。
3. 点击「当前工作空间」按钮定位到工作空间目录。
4. **预期**：文件树导航到工作空间目录，该目录已被勾选为数据源。

## 测试用例

### TC-FILE-001：页面加载与状态展示

**前置**：无

| 步骤 | 操作                           | 预期结果                                                                                       |
| ---- | ------------------------------ | ---------------------------------------------------------------------------------------------- |
| 1    | 点击侧边栏底部「文件系统」按钮 | 打开「智能文件系统」页面，顶部显示标题「智能文件系统」和副标题「轻松寻找，管理和组织你的文件」 |
| 2    | 观察顶部状态胶囊               | 显示「状态 · 模式」格式，如「运行中 · 完整索引」或「未配置 · 完整索引」                        |
| 3    | 观察页面结构                   | 依次显示 Banner、数据源卡片区、操作栏（提示「勾选你想让 AI 理解的文件夹」）、文件树            |

**判定**：页面标题缺失或关键区域未加载 → 失败

---

### TC-FILE-002：刷新扫描

**前置**：P-FILE-01

| 步骤 | 操作                                   | 预期结果                                                               |
| ---- | -------------------------------------- | ---------------------------------------------------------------------- |
| 1    | 点击 Banner 上的刷新按钮（⟳ 圆形按钮） | 刷新按钮变为不可点击并旋转，显示正在扫描                               |
| 2    | 等待扫描完成                           | 按钮恢复可点击；数据源卡片「最近扫描时间」更新为「刚刚」或「N 分钟前」 |

**判定**：刷新按钮无反馈或扫描后最近扫描时间未更新 → 失败

---

### TC-FILE-003：告警徽标——点击打开设置

**前置**：当前环境中嵌入模型未配置或不可用（可在设置中停用嵌入模型后重启模拟）

| 步骤 | 操作                                 | 预期结果                                                                                  |
| ---- | ------------------------------------ | ----------------------------------------------------------------------------------------- |
| 1    | 观察 Banner 上的告警徽标（⚠ 感叹号） | 显示告警提示，如「未配置嵌入模型 · 点击去配置」或「嵌入模型不可用，请检查配置或稍后重试」 |
| 2    | 点击该告警徽标                       | 打开设置编辑器，定位到文件扫描/嵌入模型配置区域                                           |

**判定**：告警徽标不可点击或点击未打开设置 → 失败；当前环境无嵌入模型告警 → SKIP

### TC-FILE-004：数据源卡片——状态展示

**前置**：P-FILE-01

| 步骤 | 操作                   | 预期结果                                                                           |
| ---- | ---------------------- | ---------------------------------------------------------------------------------- |
| 1    | 观察数据源卡片区       | 每个已配置目录显示一张卡片，含目录名称、状态文本、最近扫描时间                     |
| 2    | 观察卡片状态           | 状态显示「已完成 · N 文件」或「基础索引 · N 文件」；最近扫描时间显示「N 分钟前」等 |
| 3    | 将鼠标悬停到卡片右上角 | 显示删除按钮（×，标题「删除数据源」）                                              |

**判定**：卡片信息缺失或悬停不显示删除按钮 → 失败

### TC-FILE-005：删除数据源（取消）

**前置**：P-FILE-01（至少两个数据源，其中至少一个非当前工作空间）

| 步骤 | 操作                                           | 预期结果                                                                                                                                           |
| ---- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 悬停某个非当前工作空间数据源卡片，点击删除按钮 | 弹出确认弹窗，标题「删除数据源」，正文「删除数据源「<名称>」？此操作会清除该路径下的本地索引，但不会删除你的文件。」，底部有「删除」和「取消」按钮 |
| 2    | 点击「取消」                                   | 弹窗关闭，数据源卡片仍存在，未被删除                                                                                                               |

**判定**：弹窗未出现或取消后数据源被移除 → 失败

### TC-FILE-006：删除数据源（确认）

**前置**：P-FILE-01（至少两个数据源，其中至少一个非当前工作空间）

| 步骤 | 操作                                       | 预期结果                                                                    |
| ---- | ------------------------------------------ | --------------------------------------------------------------------------- |
| 1    | 点击某个非当前工作空间数据源卡片的删除按钮 | 弹出「删除数据源」确认弹窗                                                  |
| 2    | 点击「删除」确认按钮                       | 弹窗关闭，该数据源卡片从卡片区消失；底部页脚「已选择 N 条扫描路径」数量减少 |

**清理**：重新在文件树勾选该目录，确认其作为数据源恢复。

**判定**：确认后数据源未被移除 → 失败

### TC-FILE-010：文件树勾选——加入 AI 理解范围

**前置**：P-FILE-01

| 步骤 | 操作                           | 预期结果                                                               |
| ---- | ------------------------------ | ---------------------------------------------------------------------- |
| 1    | 勾选文件树中一个尚未选中的目录 | 右下角出现 Toast 通知「已加入 AI 理解范围「<目录名>」」，约 3 秒后消失 |
| 2    | 观察数据源卡片区               | 该目录生成新的数据源卡片                                               |
| 3    | 观察底部页脚                   | 「已选择 N 条扫描路径」数量增加 1                                      |

### TC-FILE-011：文件树取消勾选——忽略与撤销

**前置**：P-FILE-01

| 步骤 | 操作                           | 预期结果                                                                  |
| ---- | ------------------------------ | ------------------------------------------------------------------------- |
| 1    | 取消勾选文件树中一个已选目录   | 右下角出现 Toast 通知「已忽略这个文件夹「<目录名>」」，并显示「撤销」按钮 |
| 2    | 点击「撤销」按钮               | 出现「已撤销」提示，目录恢复为勾选状态，数据源卡片保留                    |
| 3    | 再次取消勾选该目录，等待 10 秒 | 「撤销」按钮消失，数据源卡片被移除，「已选择 N 条扫描路径」数量减少       |

**判定**：忽略通知未出现、撤销无效或撤销后数据源仍被移除 → 失败

### TC-FILE-013：文件扫描配置——添加目录

**前置**：无

1. 打开设置，进入「文件扫描配置」区域。

| 步骤 | 操作                               | 预期结果                                                                        |
| ---- | ---------------------------------- | ------------------------------------------------------------------------------- |
| 1    | 观察目录列表                       | 显示「暂无配置目录」空状态，或已配置目录列表（每项带「删除」入口）              |
| 2    | 点击「+ 添加新目录」               | 进入输入状态，输入框预填家目录，提示「输入要扫描的目录路径（例: ~/Documents）」 |
| 3    | 输入一个不存在的路径，按 Enter     | 输入框标红，显示「路径不存在或无权限访问: <路径>」，不保存                      |
| 4    | 输入一个文件路径而非目录，按 Enter | 显示「不是目录: <路径>」，不保存                                                |
| 5    | 输入一个已存在的目录，按 Enter     | 目录保存到列表，返回列表视图，触发扫描器重启                                    |

**判定**：无效路径未报错、或有效路径添加后未出现在列表 → 失败

### TC-FILE-015：文件工具调用卡片——语义搜索

**前置**：一个运行中的任务；P-FILE-01；已配置可用的嵌入模型

| 步骤 | 操作                                 | 预期结果                                                                                   |
| ---- | ------------------------------------ | ------------------------------------------------------------------------------------------ |
| 1    | 在对话中要求 AI 对本地文件做语义搜索 | 会话中渲染「语义搜索」工具卡片，显示查询词与结果上限                                       |
| 2    | 执行期间观察卡片                     | 显示「搜索中...」状态徽标                                                                  |
| 3    | 等待完成                             | 卡片显示结果列表，含匹配文件标题、内容片段；无结果时显示「未找到与“<查询>”匹配的本地文件」 |

**判定**：工具卡片未渲染或执行成功后无结果展示 → 失败；网络/模型不可用 → BLOCKED

## 未覆盖的模块

- 文件工具调用卡片中的读取/写入/编辑/提取文本/读取图片等细分卡片行为（本次仅覆盖语义搜索作为代表）。
- 多种嵌入模型告警的具体文案差异（未配置/不可用/维度不支持）的逐一验证。
- 文件树深层展开、跨目录多选组合。
