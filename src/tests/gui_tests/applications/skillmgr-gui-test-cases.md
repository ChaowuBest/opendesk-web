# 技能中心 (Skill Center) GUI 验收测试用例

---

## 前置条件

### P-SKILL-06：准备一个有效的技能目录

一个有效的技能目录是指包含 `SKILL.md` 文件的文件夹。`SKILL.md` 文件开头必须有 frontmatter（用 `---` 包围），其中至少包含 `name` 和 `description` 字段。

**方式一：使用项目自带的测试技能**

OpenDesk 自带两个测试技能，位于用户数据目录下：

- `~/.opendesk/apps/skills/resources/test-normal`
- `~/.opendesk/apps/skills/resources/test-normal-1`

1. 打开技能中心「已安装」标签页，点击右上角「+」→「从目录安装」。
2. 在弹出的文件选择器中，导航到上述路径之一，选择该文件夹。
3. **预期**：技能安装成功，列表中出现对应技能卡片。

**方式二：手动创建一个技能目录**

1. 在本地任意位置创建一个新文件夹，如 `my-test-skill`。
2. 在该文件夹内创建 `SKILL.md` 文件，写入以下内容：

    ```
    ---
    name: my-test-skill
    description: A test skill for verification
    ---

    # My Test Skill

    This is a test skill.
    ```

3. 后续通过「从目录安装」选择该文件夹即可。

### P-SKILL-07：准备一个有效的技能 ZIP 文件

1. 先按 P-SKILL-06 方式二创建一个技能目录。
2. 将该文件夹压缩为 `.zip` 文件（确保 ZIP 内根目录直接包含 `SKILL.md`，而非嵌套一层文件夹）。
    - macOS：右键文件夹 →「压缩」
    - 命令行：`cd` 到技能目录的父目录，执行 `zip -r skill.zip my-test-skill/`
3. **预期**：得到一个 `.zip` 文件，解压后根目录可见 `SKILL.md`。

### P-SKILL-08：准备一个包含多个技能子目录的目录

1. 在本地创建一个父目录，如 `test-skills-batch`。
2. 在该目录下创建两个子目录，每个子目录各包含一个 `SKILL.md`：
    - `test-skills-batch/skill-a/SKILL.md`（name: skill-a）
    - `test-skills-batch/skill-b/SKILL.md`（name: skill-b）
3. **预期**：父目录下有两个子目录，每个子目录包含有效的 `SKILL.md`。

### P-SKILL-01：已安装至少一个技能

1. 打开技能中心「已安装」标签页，确认列表不为空。
2. 若为空，按 P-SKILL-06 方式一安装 `test-normal` 技能。
3. **预期**：列表显示至少一个技能卡片。

### P-SKILL-02：已安装多个技能（含可禁用状态）

1. 按 P-SKILL-06 方式一安装 `test-normal`，再安装 `test-normal-1`（同一目录下另一个测试技能）；或按方式二创建两个不同的技能目录并分别安装。
2. 在「已安装」标签页中，将其中一个技能的开关关闭。
3. **预期**：列表显示 ≥2 个技能卡片，被关闭的技能显示为"已禁用"。
4. **清理**：回到该技能卡片，点击开关将其重新启用，确认开关恢复为"已启用"状态。

### P-SKILL-03：Registry 搜索有结果

1. 切换到任意 Registry 标签页（如 OpenHarmony Matrix），输入关键词搜索。
2. **预期**：显示搜索结果或"未找到结果"空状态。
3. 若网络不可达，标记 BLOCKED。

### P-SKILL-04：分析与优化——已选中技能

1. 切换到「分析与优化」标签页。
2. 勾选至少一个技能的复选框。
3. **预期**：工具栏按钮从不可点击变为可点击。

### P-SKILL-05：已安装一个黑名单技能

1. 按 P-SKILL-01 安装一个技能，记录其名称（如 `test-normal`）。
2. 找到 OpenDesk 用户数据目录（打开技能中心「已安装」标签页，空状态提示中会显示安装路径，该路径的上级目录即为用户数据目录下的 `apps/skills`）。
3. 在 `apps` 目录下创建或编辑 `blacklist.json` 文件，添加以下内容（将 `test-normal` 替换为实际技能名称）：
    ```json
    {
        "skillmgr/test-normal": {
            "reason": "测试用恶意技能",
            "blockedAt": "2026-01-01T00:00:00.000Z",
            "evidence": "该技能试图执行危险操作，用于测试黑名单功能"
        }
    }
    ```
4. 返回技能中心，点击右上角刷新按钮（↻ 图标）。
5. **预期**：该技能卡片显示红色边框和"⚠ 恶意skill"标签。

### TC-SKILL-016：外部技能面板（条件可用）

**前置**：在 OpenDesk 设置中配置外部技能路径并重启

1. 打开 OpenDesk 设置页面（点击侧边栏「设置」或使用 `/config` 命令）。

4. 打开技能中心，确认标签栏出现「🗂️ 外部技能」标签。

| 步骤 | 操作                   | 预期结果                                                 |

| 1    | 观察标签栏             | 当外部技能数量 > 0 时，显示「🗂️ 外部技能」标签及数量角标 |
| 2    | 点击「外部技能」标签页 | 卡片显示技能名称和「外部」标签                           |
| 3    | 点击某个外部技能卡片   | 详情对话框显示技能信息，底部只有「完成」按钮（非关键）   |

**判定**：未配置外部技能路径时 SKIP；配置后标签不显示 → 失败
