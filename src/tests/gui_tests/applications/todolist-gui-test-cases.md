# 待办 (Todolist) GUI 验收测试用例

---

## 前置条件

### P-TODO-01：全局待办管理页面已打开

1. 点击侧边栏底部「应用」按钮，在应用列表中找到「自动化任务」或「待办管理」应用。
2. 点击打开。
3. **预期**：自动化任务管理页面加载，显示标题"自动化任务"。

---

## 测试用例

### TC-TODO-001：任务级待办——面板展示

**前置**：侧边栏已有至少一个任务；当前任务有 Agent 通过 TodoWrite 创建的待办项

| 步骤 | 操作                   | 预期结果                                          |
| ---- | ---------------------- | ------------------------------------------------- |
| 1    | 观察右侧"任务计划"面板 | 面板标题显示"当前待办"，下方列出所有待办项        |
| 2    | 观察待办项摘要         | 显示"已完成 X 项 · 进行中 X 项 · 未开始 X 项"摘要 |
| 3    | 观察单个待办项         | 显示标题、状态图标和状态标签（进行中/待开始）     |

**判定**：待办面板未显示或摘要信息缺失 → 失败

---

### TC-TODO-002：任务级待办——状态流转与计时

**前置**：侧边栏已有至少一个任务；当前任务有待办项且 Agent 正在执行

| 步骤 | 操作                       | 预期结果                                         |
| ---- | -------------------------- | ------------------------------------------------ |
| 1    | 观察状态为"进行中"的待办项 | 显示旋转图标和"进行中"标签                       |
| 2    | 等待一段时间后观察         | 显示"已执行 X 分 X 秒"计时信息                   |
| 3    | 等待该待办完成             | 状态变为"已完成"，计时信息更新为"用时 X 分 X 秒" |

**判定**：计时信息未显示或状态未流转 → 失败

---

### TC-TODO-003：任务级待办——完成标记

**前置**：侧边栏已有至少一个任务；当前任务有已完成的待办项

| 步骤 | 操作                     | 预期结果                                 |
| ---- | ------------------------ | ---------------------------------------- |
| 1    | 观察已完成的待办项       | 标题显示删除线样式，左侧显示完成图标 ✓   |
| 2    | 观察所有待办完成后的面板 | 所有待办项仍保留在面板中（不会自动清空） |

**判定**：已完成项未显示删除线或全部完成后面板被清空 → 失败

### TC-TODO-004：全局待办——页面加载与空状态

**前置**：P-TODO-01；当前无已创建的自动化任务

| 步骤 | 操作                         | 预期结果                                               |
| ---- | ---------------------------- | ------------------------------------------------------ |

| 2    | 观察模板区域                 | 显示"可以试试从这些常见任务入手"标题和模板卡片网格     |
| 3    | 观察"已创建的自动化任务"区域 | 显示"暂无自动化任务"和"点击上方模板快速创建"空状态提示 |

### TC-TODO-005：全局待办——创建自动化任务

**前置**：P-TODO-01

| 步骤 | 操作                                     | 预期结果                                                             |
| ---- | ---------------------------------------- | -------------------------------------------------------------------- |
| 1    | 点击「创建」按钮                         | 右侧打开编辑面板，标题为"新建任务"                                   |
| 2    | 填写标题（如"每日新闻推送"）             | 标题输入正常                                                         |
| 3    | 填写内容（如"帮我总结今日 AI 领域新闻"） | 内容输入正常                                                         |
| 4    | 选择触发类型为"定时（一次性）"           | 显示日期时间选择器                                                   |
| 5    | 选择一个未来的日期和时间                 | 日期时间选择器显示所选值                                             |
| 6    | 点击「创建」按钮                         | 编辑面板关闭；左侧列表出现新创建的自动化任务卡片，显示"定时任务"标签 |

**判定**：创建后任务卡片未出现在列表中 → 失败

### TC-TODO-006：全局待办——从模板快速创建

**前置**：P-TODO-01

| 步骤 | 操作             | 预期结果                                                   |
| ---- | ---------------- | ---------------------------------------------------------- |

| 2    | 点击某个模板卡片 | 右侧打开编辑面板，标题和内容已预填充模板内容               |
| 3    | 点击「创建」按钮 | 编辑面板关闭；左侧列表出现新创建的自动化任务卡片           |

**判定**：模板内容未预填充或创建后任务未出现 → 失败

### TC-TODO-008：全局待办——编辑任务

**前置**：P-TODO-01；已创建至少一个自动化任务

| 步骤 | 操作                                     | 预期结果                                       |
| ---- | ---------------------------------------- | ---------------------------------------------- |
| 1    | 打开某个任务的详情面板，点击「编辑」按钮 | 详情面板切换为编辑模式，标题变为"编辑任务"     |
| 2    | 修改标题内容                             | 标题可正常编辑                                 |
| 3    | 修改触发方式（如从"定时"改为"周期"）     | 显示 Cron 构建器，可选择重复频率               |
| 4    | 点击「保存」按钮                         | 编辑面板关闭或切换回详情模式；任务卡片信息更新 |

**判定**：保存后修改未生效 → 失败

### TC-TODO-009：全局待办——删除任务（取消）

**前置**：P-TODO-01；已创建至少一个自动化任务

| 步骤 | 操作                                     | 预期结果                                                        |
| ---- | ---------------------------------------- | --------------------------------------------------------------- |
| 1    | 打开某个任务的详情面板，点击「删除」按钮 | 弹出确认模态框，内容为"确定要删除任务「…」吗？此操作不可撤销。" |
| 2    | 点击「取消」                             | 模态框关闭，任务仍存在于列表中                                  |

**判定**：确认弹窗未出现或取消后任务被删除 → 失败

### TC-TODO-010：全局待办——删除任务（确认）

### TC-TODO-011：全局待办——启用/禁用切换

**前置**：P-TODO-01；已创建至少一个自动化任务

| 步骤 | 操作                           | 预期结果                           |
| ---- | ------------------------------ | ---------------------------------- |
| 1    | 观察某个自动化任务卡片上的开关 | 显示当前状态（"启用中"或"未启用"） |
| 2    | 点击开关                       | 开关状态翻转；卡片上的状态标签更新 |
| 3    | 再次点击开关                   | 开关恢复原状态                     |

**判定**：开关状态未翻转 → 失败

### TC-TODO-012：全局待办——立即执行

**前置**：P-TODO-01；已创建至少一个自动化任务

| 步骤 | 操作                                         | 预期结果                               |
| ---- | -------------------------------------------- | -------------------------------------- |
| 1    | 打开某个任务的详情面板，点击「立即执行」按钮 | 按钮变为"触发中..."不可再次点击        |
| 2    | 等待触发完成                                 | 按钮恢复为"立即执行"；状态变为"已触发" |

**判定**：触发后按钮未变化或触发失败 → 失败

### TC-TODO-013：全局待办——Cron 触发器构建器

**前置**：P-TODO-01

| 步骤 | 操作                                           | 预期结果                             |
| ---- | ---------------------------------------------- | ------------------------------------ |
| 1    | 点击「创建」按钮，选择触发类型为"周期（Cron）" | 显示 Cron 构建器，包含"重复频率"选择 |
| 2    | 选择"每天"                                     | 显示"执行时间"选择器                 |
| 3    | 选择一个时间（如 09:00）                       | 时间选择器显示所选值                 |
| 4    | 切换到"每周指定日"                             | 显示星期选择器                       |
| 5    | 选择某几个星期，设置时间                       | 设置值正常显示                       |
| 6    | 切换到"自定义 Cron 表达式"                     | 显示 Cron 表达式输入框               |
| 7    | 输入有效的 Cron 表达式（如 `0 9 * * 1-5`）     | 输入正常接受                         |

**判定**：Cron 构建器缺失或切换选项不生效 → 失败
