# 目标 (Goal) GUI 验收测试用例

---

## 前置条件

### P-GOAL-01：当前任务有活跃的 Goal

1. 打开一个任务，在输入框中输入 `/goal 完成一个示例任务`，按 Enter。
2. 等待 Goal 创建成功，观察右侧面板出现 Goal 面板。
3. **预期**：Goal 面板显示目标文本，状态为"进行中"。

### P-GOAL-02：当前任务有待办且无 Goal

1. 打开一个任务，向 Agent 发送一条需要多步执行的请求（如"帮我分析一个项目的目录结构并总结"）。
2. 等待 Agent 通过 TodoWrite 工具创建待办项。
3. 确认右侧"任务计划"面板出现待办项，且无 Goal 面板。
4. **预期**：Goal 建议横幅出现。

---

## 测试用例

### TC-GOAL-001：Goal 建议横幅——显示与操作

**前置**：P-GOAL-02

| 步骤 | 操作                 | 预期结果                                                           |
| ---- | -------------------- | ------------------------------------------------------------------ |
| 1    | 观察右侧任务计划面板 | 出现建议横幅，内容为"是否需要为本次任务设置一个可追踪和验收的目标" |
| 2    | 观察横幅按钮         | 显示「设置目标」和「暂不需要」两个按钮                             |

**判定**：建议横幅未出现 → 失败

---

### TC-GOAL-002：Goal 建议——点击"暂不需要"

**前置**：P-GOAL-02

| 步骤 | 操作                             | 预期结果     |
| ---- | -------------------------------- | ------------ |
| 1    | 点击建议横幅中的「暂不需要」按钮 | 建议横幅消失 |

**判定**：点击后横幅未消失 → 失败

---

### TC-GOAL-003：通过 GUI 面板创建 Goal

**前置**：P-GOAL-02

| 步骤 | 操作                                           | 预期结果                                             |
| ---- | ---------------------------------------------- | ---------------------------------------------------- |
| 1    | 点击建议横幅中的「设置目标」按钮               | 出现创建表单，包含目标描述输入区域和「开始跟进」按钮 |
| 2    | 在输入框中输入目标描述（如"完成一份测试报告"） | 文本正常输入                                         |
| 3    | 点击「开始跟进」按钮                           | Goal 面板显示目标文本，顶部状态徽章显示"进行中"      |

**判定**：Goal 未创建或状态未显示为"进行中" → 失败

---

### TC-GOAL-004：通过 /goal 命令创建 Goal

**前置**：当前任务无 Goal

| 步骤 | 操作                                                        | 预期结果                                                         |
| ---- | ----------------------------------------------------------- | ---------------------------------------------------------------- |
| 1    | 在输入框中输入 `/goal 完成代码重构并确保测试通过`，按 Enter | Goal 创建成功，右侧面板出现 Goal 面板，显示目标文本              |
| 2    | 观察状态徽章                                                | 显示"进行中"                                                     |
| 3    | 观察任务名称                                                | 若原任务名为"未命名任务"，任务名称自动更新为与目标描述相关的名称 |

**判定**：Goal 未创建或状态不正确 → 失败

---

### TC-GOAL-005：创建 Goal——空目标校验

**前置**：当前任务无 Goal

| 步骤 | 操作                             | 预期结果                      |
| ---- | -------------------------------- | ----------------------------- |
| 1    | 点击「设置目标」按钮打开创建表单 | 输入框为空                    |
| 2    | 不输入任何内容，点击「开始跟进」 | 显示"Goal 目标不能为空。"提示 |

**判定**：空目标被允许创建 → 失败

---

### TC-GOAL-006：Goal 编辑——行内编辑

**前置**：P-GOAL-01

| 步骤 | 操作                           | 预期结果                                                  |
| ---- | ------------------------------ | --------------------------------------------------------- |
| 1    | 点击 Goal 面板中的目标描述文本 | 目标文本变为可编辑的文本区域                              |
| 2    | 修改目标文本                   | 文本可正常编辑                                            |
| 3    | 点击「保存」按钮               | 目标文本更新，显示修改后的内容；Goal 面板不再显示编辑模式 |

**判定**：编辑模式未进入或保存后内容未更新 → 失败

---

### TC-GOAL-007：Goal 编辑——通过 /goal 命令编辑

**前置**：P-GOAL-01

| 步骤 | 操作                                              | 预期结果                                   |
| ---- | ------------------------------------------------- | ------------------------------------------ |
| 1    | 在输入框中输入 `/goal 更新后的目标描述`，按 Enter | 弹出确认对话框，显示当前目标和修改后的目标 |
| 2    | 点击「修改 Goal」按钮                             | 对话框关闭，Goal 面板更新为新的目标文本    |

**判定**：确认对话框未弹出或确认后目标未更新 → 失败

---

### TC-GOAL-008：Goal 暂停与恢复

**前置**：P-GOAL-01

| 步骤 | 操作                           | 预期结果                                      |
| ---- | ------------------------------ | --------------------------------------------- |
| 1    | 点击 Goal 面板中的「暂停」按钮 | 状态徽章变为"已暂停"；正在运行的 Agent 被中断 |
| 2    | 点击「恢复」按钮               | 状态徽章恢复为"进行中"；Agent 重新开始执行    |

**判定**：暂停后状态未变为"已暂停"或恢复后未变为"进行中" → 失败

---

### TC-GOAL-009：Goal 清除

**前置**：P-GOAL-01

| 步骤 | 操作                           | 预期结果                                                                      |
| ---- | ------------------------------ | ----------------------------------------------------------------------------- |
| 1    | 点击 Goal 面板中的「清除」按钮 | 状态徽章变为"已清除"；正在运行的 Agent 被中断；任务级待办中的"进行中"项被重置 |

### TC-GOAL-010：Goal 评估结果展示

**前置**：P-GOAL-01；Goal 已执行一段时间且 Evaluator 已完成至少一次评估

| 步骤 | 操作                       | 预期结果                                            |
| ---- | -------------------------- | --------------------------------------------------- |
| 1    | 观察 Goal 面板中的评估卡片 | 显示评估状态标签（已达成/未达成/已阻塞/评估失败等） |
| 2    | 查看评估原因               | 显示评估原因文本                                    |
| 3    | 查看证据区域               | 显示"证据"标题和证据列表                            |

**判定**：评估结果卡片缺失或关键信息缺失 → 失败

---

### TC-GOAL-011：Goal 评估中状态展示

**前置**：P-GOAL-01；Goal 正在执行且 Evaluator 正在评估中

| 步骤 | 操作           | 预期结果                                      |
| ---- | -------------- | --------------------------------------------- |
| 1    | 观察 Goal 面板 | 显示"正在评估目标达成情况..."提示，带旋转图标 |

**判定**：评估中状态未显示 → 失败

---

### TC-GOAL-012：Goal 补充信息——等待进入上下文

**前置**：P-GOAL-01；Goal 正在执行中

| 步骤 | 操作                   | 预期结果                                         |
| ---- | ---------------------- | ------------------------------------------------ |
| 1    | 在输入框中发送一条消息 | 消息显示为补充信息，标签显示"等待进入上下文"     |
| 2    | 等待当前工具执行完成   | 补充信息标签更新为"已进入上下文，等待 LLM 响应…" |

**判定**：补充信息标签未显示或状态未更新 → 失败

---

### TC-GOAL-013：Goal 时间线展示

**前置**：P-GOAL-01；Goal 已经历创建、编辑或暂停等事件

| 步骤 | 操作                             | 预期结果                                                                 |
| ---- | -------------------------------- | ------------------------------------------------------------------------ |
| 1    | 点击 Goal 面板中的「时间线」按钮 | 展开时间线区域，显示按时间排列的事件列表                                 |
| 2    | 观察事件列表                     | 每个事件显示事件类型标签（已创建/已编辑/已暂停/已恢复/已评估等）和时间戳 |
| 3    | 点击创建或编辑事件               | 聊天区域滚动到对应的消息位置                                             |

**判定**：时间线未展示或事件类型标签缺失 → 失败

---

### TC-GOAL-014：Goal 输入拦截提示

**前置**：P-GOAL-01；Goal 正在执行中（Agent 正在处理工具调用）

| 步骤 | 操作                       | 预期结果                                                                       |
| ---- | -------------------------- | ------------------------------------------------------------------------------ |
| 1    | 在输入框中发送一条普通消息 | 出现提示，内容为"Goal 正在执行，你的消息已作为补充信息加入…"，而非普通消息入队 |

**判定**：消息未作为补充信息处理或提示未出现 → 失败

## 未覆盖的模块

- `/goal` 命令的 help 子命令（仅展示帮助文本，低优先级）。
- Goal 乐观锁冲突处理（需并发操作场景，难以稳定复现）。
- Goal 自动阻塞与恢复（需特定运行时错误触发，难以稳定复现）。
