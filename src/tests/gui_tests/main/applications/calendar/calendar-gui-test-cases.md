# 日历 (Calendar) GUI 验收测试用例

---

## 前置条件

### P-CAL-01：日历应用已打开

1. 点击侧边栏底部「应用」按钮（或侧边栏导航区的「应用」按钮），在应用列表中找到「日历」应用。
2. 点击打开。
3. **预期**：日历应用页面加载，显示月视图和左侧迷你日历。

### P-CAL-02：已有至少一个日程

1. 按 P-CAL-01 打开日历应用。
2. 点击工具栏「添加日程」按钮，在弹出的模态框中填写标题「测试会议」、选择今天的日期、设置开始时间 10:00、结束时间 11:00、类型选择「会议」，点击「添加」。
3. **预期**：日历视图中出现对应的事件色块。

### P-CAL-03：已有多个日程（含不同类型）

1. 按 P-CAL-02 添加一个日程。
2. 再添加一个全天事件：标题「项目截止日」、勾选「全天」、类型选择「截止日期」，点击「添加」。
3. 再添加一个定时事件：标题「视频周会」、选择明天日期、时间 14:00-15:00、类型选择「视频通话」、地点「线上」，点击「添加」。
4. **预期**：日历视图中出现 ≥3 个日程，涵盖不同类型。
