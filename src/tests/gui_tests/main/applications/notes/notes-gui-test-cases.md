# 笔记 (Notes) GUI 验收测试用例

---

## 前置条件

### P-NOTE-01：已创建至少一条笔记

1. 在侧边栏底部「应用」按钮 → 应用列表中找到「笔记」并点击打开。
2. 点击左上角「新建」按钮。
3. 在标题输入框中输入笔记标题（如"测试笔记"）。
4. 在正文编辑区输入一些文本内容。
5. **预期**：笔记保存成功，左侧列表出现该笔记卡片。

### P-NOTE-02：已有至少两条笔记

1. 按 P-NOTE-01 创建至少两条笔记，标题和内容各不相同。
2. **预期**：左侧列表显示至少两条笔记卡片。

### P-NOTE-03：已有笔记且带有标签

1. 按 P-NOTE-01 创建一条笔记。
2. 在编辑器中点击标签区域的「+」按钮，选择一个已有标签或创建新标签。
3. **预期**：笔记标题下方显示标签 pill。

### P-NOTE-04：回收站中至少有一条笔记

1. 按 P-NOTE-01 创建一条笔记。
2. 在笔记编辑器中点击「删除」按钮，在确认弹窗中点击「删除」。
3. **预期**：笔记从列表消失，左侧「已删除」条目计数增加。
