# 🔍 桶2: 找不到命令或工具

找不到命令或工具是执行时最常碰到的问题，本章节汇总了鸿蒙 PC 生态建立中的开发者常用命令行工具、编程语言运行时等适配支持，请参考本章节完成缺失命令或工具的安装下载。

如果根据本章节的指引，确认缺失的命令或工具在鸿蒙 PC 上暂未支持，可采用最终兜底方案：**可从本机 local 节点切换到 Headless Node 的 Linux 环境执行（通过 `executeNodeShell`）**。
